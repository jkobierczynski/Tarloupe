The first release of Tarloupe: browse huge `.tar` and `.tar.gz` archives on Windows without extracting them. The first open builds a seek index in one pass; after that, any file inside opens in milliseconds.

## Install

Download `tarloupe-setup-0.1.0-x64.exe` and run it. It installs [WinFsp](https://winfsp.dev) 2.1 if no version is installed yet, then Tarloupe for all users. `tarloupe-0.1.0-x64.msi` is Tarloupe alone, for machines that already have WinFsp. Uninstalling leaves WinFsp in place.

**The installers are not code-signed yet**, so Windows SmartScreen warns when you run them ("More info", then "Run anyway"). `SHA256SUMS.txt` lists their checksums.

## What's in it

- **Browse with Tarloupe** in the Explorer right-click menu for `.tar`, `.tgz` and `.tar.gz` files (on Windows 11, under "Show more options"). The archive opens as a read-only drive and unmounts by itself once nothing on it has been in use for two minutes.
- A tray icon while archives are mounted, with Open and Unmount for each, and "Unmount all and quit".
- `tarloupe mount` to mount an archive on a drive letter or folder, and `tarloupe index`, `list`, `ls`, `cat` and `extract` on the command line.
- gzip archives get checkpoints every 8 MiB, so reading one file out of a 4 GiB `.tar.gz` takes about 30 ms instead of 10 to 20 seconds.
